# 🇵🇱 Zaczynam mówić po polsku (A0 → B2)

Образовательная игра-приложение (Local-First PWA) для системного изучения польского языка от начального уровня **A0** до уверенного **B2**, адаптированная для белорусов и русскоязычных экспатов, живущих в Польше.

Главная цель проекта — дать не просто набор карточек, а **последовательную обучающую систему** для реальной жизни в Польше (*Urząd Miasta, Urząd Wojewódzki, NFZ, ZUS, работа, аренда жилья, школа, банк*) и подготовки к сертификационным экзаменам:
- **Рубеж №1 (Уровень B1):** документальное подтверждение языка для получения статуса **долгосрочного резидента ЕС** (*zezwolenie na pobyt rezydenta długoterminowego UE*) и **гражданства РП** (*uznanie za obywatela polskiego*).
- **Рубеж №2 (Уровень B2):** свободная профессиональная коммуникация, аргументация и сдача государственного экзамена **Państwowej Komisji do spraw Poświadczania Znajomości Języka Polskiego jako Obcego** (`certyfikatpolski.pl`).

## ✨ Ключевые особенности

- **Заточка под восточнославянскую интерференцию (`Pułapki Językowe`):**
  Приложение целенаправленно отслеживает и объясняет типичные ошибки белорусов и русскоязычных:
  - вежливое обращение через **3-е лицо** (`Czy ma Pan/Pani czas?` вместо кальки *«Czy wy macie czas?»*);
  - обязательное сохранение связки **być** в настоящем времени (`Jestem z Białorusi`);
  - склонение слова **Pan** в косвенных падежах (`Pan / Pana / Panu`);
  - «ложные друзья переводчика» (`jutro` = завтра, `rano` = утром, `sklep` = магазин, `parter` = 1-й этаж с уровня земли, `pierwsze piętro` = наш 2-й этаж, `dywan` = ковёр, `zapomnieć` = забыть);
  - управление польских глаголов (*rekcja czasowników*: `szukać + Dopełniacz`, `złożyć wniosek o + Biernik`, `dziękować + Celownik`).
- **Двухступенчатое интервальное повторение (SRS с морфологией):**
  - *Ступень 1 (Recognition):* пассивное узнавание слова на слух и в контексте;
  - *Ступень 2 (Active Morphology):* подстановка слова в предложение **в нужной падежной или глагольной форме** (слово считается вошедшим в активный запас только после успешного воспроизведения формы с интервалом ≥ 14 дней).
- **Умный валидатор польского ввода:**
  - экранная клавиатура польских диакритических символов (`ą, ć, ę, ł, ń, ó, ś, ź, ż`);
  - на уровнях `A0–A1` ответы с пропущенной диакритикой (`Nazywam sie Pawel`) засчитываются с мягким предупреждением и подсветкой нужных букв, а в режиме экзаменационного тренажёра `B1/B2` оцениваются строго.
- **Сюжетные миссии реальной польской жизни:**
  Каждый модуль завершается практическим квестом (в Модуле 1 — получение талона в терминале *Urząd Miasta*, диалог с инспектором у окошка и проверка заявления на номер **PESEL**).
- **Нейросетевая польская озвучка + Offline-First:**
  Все диалоги, примеры и словарь озвучены польскими нейроголосами (`pl-PL-ZofiaNeural` и `pl-PL-MarekNeural`) с возможностью замедления (`0.78x`) и автоматическим откатом на браузерный `Web Speech API (pl-PL)`. Прогресс хранится локально в браузере (`IndexedDB / Dexie.js`).

## 🛠 Технологический стек

- **Frontend Framework:** [Next.js 15 (App Router)](https://nextjs.org/) + React 19 + TypeScript
- **Стилизация:** [Tailwind CSS v4](https://tailwindcss.com/) + [Lucide Icons](https://lucide.dev/)
- **State Management & Persistence:** [Zustand](https://zustand-demo.pmnd.rs/) + [Dexie.js (IndexedDB)](https://dexie.org/)
- **Валидация контента (Content-as-Code):** [Zod](https://zod.dev/)
- **Тестирование:** [Vitest](https://vitest.dev/)
- **Генерация аудио:** Python [`edge-tts`](https://github.com/rany2/edge-tts) (`pl-PL-ZofiaNeural`, `pl-PL-MarekNeural`)

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

*(Опционально, если вы хотите перегенерировать или добавлять новые аудиофайлы через Python-скрипт):*

```bash
pip install edge-tts
```

### 2. Запуск в режиме разработки

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### 3. Полезные команды

| Команда | Описание |
| :--- | :--- |
| `npm run dev` | Запуск локального сервера разработки (`http://localhost:3000`) |
| `npm run validate:content` | Проверка всех учебных модулей по `Zod`-схеме (`scripts/validate-content.ts`) |
| `npm test` | Запуск unit-тестов валидатора ответов и планировщика SRS (`Vitest`) |
| `npm run generate:audio` | Генерация польских MP3-файлов озвучки в `public/audio/` |
| `npm run build` | Продакшен-сборка приложения |

## 🗺 Дорожная карта релизов (цикл: каждые 2 недели)

- [x] **Релиз 1 (`mod-a0-01`, Уровень A0):** Произношение, ударение, формула *Pan/Pani + 3 л.*, глагол *być*, миссия на получение *PESEL* в *Urząd Miasta*.
- [ ] **Релиз 2 (`mod-a1-01`, Уровень A1.1):** *Kim jesteś i skąd pochodzisz?* Спряжения настоящего времени (`-am/-asz`, `-ę/-esz`, `-ować`) и *Narzędnik* (профессии и национальности).
- [ ] **Релиз 3 (`mod-a1-02`, Уровень A1.1):** Покупки, супермаркет, *BLIK*, касса самообслуживания и *Biernik* (Винительный падеж).
- [ ] **Релиз 4 (`mod-a1-03`, Уровень A1.2):** *Czego nie ma?* Отрицание, количество, даты, глаголы *szukać / potrzebować* и *Dopełniacz* (Родительный падеж) + режим аудиодиктанта.
- [ ] **Релиз 5 (`mod-a1-04`, Уровень A1.2):** Город, вокзал *PKP*, общественный транспорт и *Miejscownik* (чередования основы *Polska → w Polsce, biuro → w biurze*).
- [ ] **Релиз 6 (`mod-a1-05`, Уровень A1.2):** *Czas przeszły* (прошедшее время во всех родах и лицах) + **Рубежный экзамен A1**.
- [ ] **Релизы 7–12 (Уровень A2):** Вид глагола (*aspekt*), будущее время, поликлиника *NFZ* и *Celownik*, аренда квартиры и глаголы движения, школа/дети и мужско-личный род (*rodzaj męskoosobowy*), банк, рекламации и степени сравнения + **Рубежный экзамен A2**.
- [ ] **Релизы 13–24 (Уровень B1 — Рубеж Rezydent UE):** Условное наклонение (*-bym*), склонение числительных, страдательный залог, управление 80 глаголов, грамматические трансформации (*parafrazy*) и полный 5-модульный симулятор госэкзамена **B1**.
- [ ] **Релизы 25–36 (Уровень B2 — Госэкзамен B2):** Причастия и деепричастия (*imiesłowy*), номинализация, словообразование, официальные жалобы, аргументативные эссе (250 слов) и полный симулятор госэкзамена **B2**.
